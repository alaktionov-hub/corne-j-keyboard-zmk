# Corne J ZMK configuration

This repository builds ZMK firmware for the Eyelash Peripherals Corne J keyboard with Nice!View displays.

> [!IMPORTANT]
> This keyboard is not the same as [foostan's Corne](https://github.com/foostan/crkbd) and does not work with standard `corne` firmware.

## Hardware and firmware

- The custom board definition is bundled in `boards/arm/eyelash_corne`.
- ZMK is pinned in `config/west.yml` to keep builds reproducible.
- The configuration enables Nice!View, RGB underglow, rotary encoders, mouse keys, deep sleep, and soft-off support.

The build matrix produces firmware for:

- the left half with Nice!View;
- the right half with Nice!View;
- the left half with ZMK Studio enabled;
- a `settings_reset` image for `nice_nano_v2`.

## Keymap

The keymap contains these layers:

1. `QWERTY`
2. `NUMBER`
3. `NAV`
4. `Fn`
5. `BT / RGB`
6. `Mouse`
7. `TMUX`

The `Q` and `B` tap dances are intentional:

- tap `Q` once for `Q`, or twice for `Escape`;
- tap `B` once for `B`, or twice for `Ctrl+B`.

To enter soft-off mode, hold `Q`, `S`, and `Z` together for two seconds. Press a reset switch once to wake the keyboard.
